# AUM - Azure Usage Management

## Register

product

## Users and purpose

Gateway administrators and FinOps readers working in Windows Terminal or Cloud Shell need
to see expenditure, find one team or person, and change a budget without switching tools.
The owner requires one command per task and equivalent interactive workflows.

The Overview is a monitoring dashboard: a compact KPI strip, focusable trend and
ranking panels, budget risks and anomalies. AUM adopts terminal-native density,
explicit key hints and at-a-glance gauges rather than web-style metric cards.

## Positioning

Two faces over the same governance engine: a keyboard-first console and scriptable commands.

## Design principles

Show the current month, scope, identity and freshness before a number can be mistaken.
Separate unused budget from unallocated parent headroom.
Preview changes and explain delayed enforcement; never claim a saved record is in effect.
Use familiar tables, tabs and native terminal controls, not a decorative dashboard.

## Accessibility and inclusion

Status includes words, not just colors. Support 80 by 24, keyboard and mouse, an ASCII
fallback, high contrast, no color, and linear plain output. Existing guide navy, amber
and near-black anchor the restrained terminal palette. No animation is necessary.
