# P103 Quickstart first, sections as disclosures

## Why

The owner stated the intent for this packet as:

> "my intention is to keep the sections of quickstart at the start and have sections accordions in our documentation"

>

> "crisp and follow through documentation is whats intended"

P103 applies the read-only documentation review dated 2026-10-06 to user-facing guides that are not blocked by P99/P100 merge risk. It keeps quick paths visible, folds detailed section bodies into native disclosures, preserves old headings and anchors, and records the exceptions in ADR-0056.

## Decisions

- ADR-0056 selects visible Markdown H2 headings plus one flat disclosure body for each non-terminal section.

- The rollout is test-first and staged by explicit guide enrollment in `tests/Test-DocStructure.ps1`.

- The initial run does not edit README, SETUP, UPDATE-AND-CHANGE, PROJECTION-WORKBOOK, SECURE-PROJECTION, AZ-COMMANDS, ARCHITECTURE or CHANGELOG because P99/P100 also edit them.

- Wrapping documentation changes do not alter architecture; any factual wording change cites an ADR, source file or current test.

## Acceptance criteria

- Each enrolled guide starts with H1, a factual purpose line and visible `## Quickstart`.

- The Quickstart defines required inputs before first use and states an observable expected result.

- Every other non-terminal H2 heading stays visible and its body is inside one flat disclosure with a plain-text summary and blank lines around Markdown content.

- H3 and deeper headings, fenced code blocks, image references and existing heading anchors remain available unless a slice deliberately adds a documented compatibility alias.

- The structure guard preserves the baseline heading-anchor inventory for all source guides from commit `8a4be169`.

- The permanent exceptions in ADR-0056 are enforced by reason, not by an arbitrary glob.

- Documentation guards pass after every green slice: `Test-DocReferences.ps1`, `Test-DocMarkdown.ps1`, `Test-DocStructure.ps1` and focused suites for changed pinned facts.
