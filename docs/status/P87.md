- The initial content-preservation proof compared every line of the 64 moved sections, including
  leading and trailing blank lines, and printed 7,954 moved lines: 7,870 exact, 84 link-target-only
  changes and 0 unexplained differences. Council round 1 used a broader method: all 66 original
  `##` sections from `git show 0fed315:docs/STATUS.md`, including `Commands that prove it` and
  `Next`, are matched against the split commit `eed6271` (`docs/STATUS.md` plus the
  `docs/status/*.md` blobs); each matched section is `.strip()`ed, split on `\n`, and link
  destinations are masked before comparing. That method is the recorded one because it proves both
  moved and kept sections at the approved split commit, before round 2 intentionally reformats the
  kept command and next sections. Run from the repo root:

  ```powershell
  @'
  import pathlib, re, subprocess
  repo=pathlib.Path.cwd(); split='eed6271'
  orig=subprocess.check_output(['git','show','0fed315:docs/STATUS.md']).decode('utf-8')
  secs=re.findall(r'(?ms)^## .+?(?=^## |\Z)', orig)
  paths=['docs/STATUS.md']+subprocess.check_output(['git','ls-tree','-r','--name-only',split,'docs/status'], text=True).splitlines()
  texts={p:subprocess.check_output(['git','show',f'{split}:{p}']).decode('utf-8') for p in paths}
  def norm_line(s): return re.sub(r'(!?\[[^\]]*\])\((?:<[^>]*>|[^)\s]+)([^)]*)\)', lambda m:m.group(1)+'(__LINK__'+m.group(2)+')', s)
  def lines(s): return s.replace('\r\n','\n').strip().split('\n')
  exact=link=other=total=0
  for sec in secs:
    h=sec.splitlines()[0]
    ms=[]
    for p,t in texts.items():
      ms += [(p,m.group(0)) for m in re.finditer(r'(?ms)^'+re.escape(h)+r'.*?(?=^## |\Z)',t)]
    if len(ms)!=1: print('bad match',h,len(ms)); continue
    ol,nl=lines(sec),lines(ms[0][1]); total+=len(ol)
    if len(ol)!=len(nl): print('len diff',h,len(ol),len(nl)); continue
    for a,b in zip(ol,nl):
      if a==b: exact+=1
      elif norm_line(a)==norm_line(b): link+=1
      else: other+=1; print('other',h,a,b)
  print('sections',len(secs),'total_lines',total,'exact',exact,'link_only',link,'other',other)
  '@ | python -
  ```
