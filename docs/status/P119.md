# P119 Client-declared project identifier in chargeback, 2026-10-21

### Why

Chargeback groups spend by business unit, which comes from Entra membership.
Customers also need spend by project, and one person works on several
projects, so membership cannot supply it.

### Acceptance criteria

1. The gateway reads `x-claude-project`, lower-cases it, records a value that
   matches `^[a-z0-9][a-z0-9._-]{0,63}$`, records `unspecified` when it is
   missing and `invalid` otherwise, and never refuses a request because of it.
2. The header is removed before the request reaches Foundry, and the response
   returns the recorded value in `x-claude-project`.
3. The chargeback identity trace carries `ProjectId`.
4. `ClaudeChargeback()` exposes `project_id`; `ClaudeCost()` groups metered
   spend by it and labels cache-read spend `cache (no project)`.
5. The chargeback workbook has a Project filter on every table the
   business-unit filter applies to, and a spend-by-business-unit-and-project
   table.

### Contract

[ADR-0065](../adr/0065-client-project-identifier.md). U198 (researched)
records Claude Code's `ANTHROPIC_CUSTOM_HEADERS`; U199 (assumed) records that
Desktop and Office add-in requests report `unspecified`.

### RED and GREEN

`tests/Test-ProjectAttribution.ps1` first failed 9 of 9 assertions because no
policy expression, trace field, query column or workbook element existed. The
behavior assertion compiles the policy's own C# expression and checks nine
inputs: valid, padded, upper-case, missing, blank, spaced, leading punctuation,
65 characters and non-ASCII. The suite now passes 12 assertions.

`tests/Test-ProjectAttributionMutations.ps1` copies the six files into a
sandbox, confirms the unmutated baseline, and catches 9 of 9 mutants by their
targeted assertion with the full 12-assertion count: header forwarded to
Foundry, trace field removed, leading punctuation accepted, length limit
removed, ledger default removed, cache label removed, one workbook table
unfiltered, the suite unregistered from Test-All, and the recorded project not returned to the client.

During GREEN, the workbook filter assertion initially required every
`ClaudeCost` table to filter by project. The provenance table deliberately
ignores the business-unit filter too, so the rule became: every table that
honours the business-unit filter also honours the project filter.

Regression: Ledger, Observability, USD budgets and policy, SetGatewayPolicy,
model-family quotas and mutations, Turnstile, RunnerIntegrity, TestAllSharding,
SecureProjection (template compiled with the CI-pinned Bicep 0.46.1),
AccessProfiles and Architecture all pass.

### Architecture

No component, identity, schedule or network path changes. One request header
becomes one trace field and one report column; `docs/ARCHITECTURE.md`
Telemetry and chargeback names it, and the architecture manifest hashes were
regenerated.
