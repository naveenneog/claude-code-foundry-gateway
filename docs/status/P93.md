### PLAN

Phase 1 implements the local web UI from the installer UI spike. Milestone 1 covers the launch,
token and Host checks, schema-rendered form, installer preflight, portable commands, selected-step
run and failed-step rerun through a stub. Static fallback, business-unit editing polish, Azure
prefill, plan fingerprint, screenshots, architecture, ADR-0048, mutation proof and the full docs
remain for milestone 2.

### RED
